AFT scoring charts

Event-by-event scoring charts for the U.S. Army Fitness Test (AFT, formerly the ACFT), by age group, for both standards. Effective 1 June 2025, last checked 7 July 2026. Each chart lists the result needed for every score from 0 to 100 and the minimum for 60 points.

Male or combat MOS

  • Maximum Deadlift (MDL)
  • Hand-Release Push-Up (HRP)
  • Sprint-Drag-Carry (SDC)
  • Plank (PLK)
  • Two-Mile Run (2MR)

Female, non-combat MOS

  • Maximum Deadlift (MDL)
  • Hand-Release Push-Up (HRP)
  • Sprint-Drag-Carry (SDC)
  • Plank (PLK)
  • Two-Mile Run (2MR)
